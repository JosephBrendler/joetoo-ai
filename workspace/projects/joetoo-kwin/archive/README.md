# Historical joetoo-kwin sources

Archived reference directories:

- `joetoo-kwin-poc-0/` — initial resident script and move tests
- `joetoo-kwin-poc-1/` — early bridge and launch protocol
- `joetoo-kwin-launch-poc/` — launch and broker demonstrations
- `joetoo-kwin-plan-poc/` — declarative layout planning experiment
- `joetoo-kwin-ssh-nc-poc/` — SSH connection experiments
- `joetoo-kwin-ssh-rcfile-poc/` — SSH Bash rcfile handoff and return tests
- `step1-candidate/` — coupled CLI/planner prototype, sample config and tests
- `step1.2a-candidate/` — pre-promotion OpenRC/broker candidate, tests,
  installer and native validation record

The two candidate directories retain their original contents and modes;
only their repository paths changed. Their READMEs describe their historical
development stage. The current OpenRC/broker implementation is in the parent
project directory. The Step 1 CLI and planner remain archived prototypes.
