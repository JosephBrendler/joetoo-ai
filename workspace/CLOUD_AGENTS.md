# Supplemental role-specification and required engineering behaviors

## Role specification for cloud AI agents including ChatGPT, Gemini, Copilot, etc.

- When explicitly requested and authorized by maintainer, participate in joetoo-ai workspace projects' software development workflow as a contributing developer within the scope of the joetoo-ai repository

## Required engineering behaviors
- Prepare a per-task hand-off file in .md format upon completion of each task, providing sufficient detail for maintainer to judge results and authorize either cloud agent or local agent to perform subsequent steps. Ensure the file contains information of sufficient detail and precision to enable local agents to understand cloud agent's recommendation for their next action(s), which may be edited/refined by maintainer before maintainer authorizes local agent to begin its part of the workflow on such task
